# LIVE-SHR-001 - Share Button Not Visible During Live Session in Production

* **Severity:** Medium
* **Environment:** Android 14 · Red Note 14S · Production · v1.22.0
* **Reproducibility:** 100%

## Summary
In the Production environment, while in a live session on Android, the share button is not visible, preventing the user from accessing the share functionality.

## Steps
1. Open the mobile application on the Android device in the Production environment.
2. Join an active live session.
3. Look for the share button on screen.

## Actual
The share button is not visible during the live session.

## Expected
The share button should be visible during the live session and allow the user to use the sharing feature.

## Notes
Subcategory: Functional Completeness. Missing expected share control during live sessions in Production (v1.22.0).
