# LIVE-FMT-001 - "Face to Face" Format Unavailable When Scheduling Live Event in Production

* **Severity:** High
* **Environment:** Android 14 · Red Note 14S · Production · v1.22.0
* **Reproducibility:** 100%

## Summary
In the Production environment, when scheduling a live event and browsing live debate formats, the "Face to Face" format is unavailable and cannot be selected.

## Steps
1. Open the mobile application on the Android device in the Production environment.
2. Tap "Schedule Live Event".
3. Navigate to the live formats selection screen.
4. Look for the "Face to Face" format.

## Actual
The "Face to Face" format is not available.

## Expected
The "Face to Face" format should be available for live events and selectable by the user.

## Notes
Subcategory: Functional Completeness. Missing expected live debate format option in Production (v1.22.0).
